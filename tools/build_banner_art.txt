# Artwork for the banner build_exe.bat prints - the wordmark when the build starts, then the frog
# for a build that worked or the punk skull for one that did not. Each comes in several widths
# (the pictures at roughly 87, 80 and 60 columns, the wordmark at 120 and 76) and the widest one
# that fits wins; a console too narrow for the smallest gets plain text instead, because wrapped
# ASCII art is just noise.
#
# Each picture is two blocks. "@name <patch.png>" is the drawing. "@name.colours" is one
# palette letter per character, generated from that .png by tools/make_banner_art.py - run it
# again after touching either, and do not hand-edit the colour blocks.
#
# A block whose header has no .png (@wordmark, @wordmark76) is coloured by the word rather than
# by a photo: "ribbit" is w, "FLIP" is P, and the gap between them belongs to neither. Those
# colour blocks are written by hand and make_banner_art.py passes them through untouched.
#
# Palette: k/K black felt (printed near-white, or it vanishes on a dark console), b pupil,
# p/P mohawk pink, g/G/D felt green, t tan bone, s metal, w stitching.
